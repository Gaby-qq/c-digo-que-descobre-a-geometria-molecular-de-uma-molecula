# código-que-descobre-a-geometria-molecular-de-uma-molécula

esse código tem como objetivo definir a geometria molecular através das variáveis pares_esterioativos, pares_ligantes e pares_isolados presentes na molecula.

O usuário será direcionado para o Menu, onde escolhe se irá começar o programa ou ver informações sobre o assunto de geometria molecular.
Se o usuário escolher descobrir a geometria, deve inserir o número das variáveis(pares_esterioativos, pares_ligantes e pares_isolados) em seguida o programa verifica se todas as variáveis coincidem com alguma geometria presente no código, se não, manda um aviso na tela caso ocorra algum erro.

# Detalhes
-O programa foi escrito em C++
-Antes de começar, criamos uma função que vai de geometria linear até tetraédrica.
  -a função confere se alguma geometria está de acordo com as informações inseridas.
  -Em seguida é definida a geometria molecular e mostra o texto com a informações digitadas.
